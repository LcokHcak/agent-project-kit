# BOARD · 任务板

> 状态：`Inbox`（想法，没写说明书）→ `Ready`（说明书已写，可以开工）→ `In progress` → `Review` → `Done`。另有 `Blocked`（写明卡在哪）和 `Voided`（作废，写明原因）。
> 编号：{{ID_SCHEME}}。编号不复用，作废的任务也留着编号。
> 「谁在做」填人名或会话名。同一时间一个任务只能有一个人做。
> 这张表会被机械检查：编号不能重复；`Ready`、`In progress`、`Review` 里的任务必须有说明书（类型为「杂务」的除外）；`Done` 要写证据。
